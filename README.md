# meu-primeiro-pr

Repositório de prática para aprender o fluxo de Pull Requests no GitHub.

## Sobre

Este repositório foi criado para exercitar o fluxo completo de contribuição via Git e GitHub:

1. Criar uma branch
2. Fazer uma alteração
3. Commitar e dar push
4. Abrir um Pull Request
5. Revisar e fazer o merge

## Como contribuir

```bash
git checkout -b minha-branch
# faça suas alterações
git add .
git commit -m "descrição da mudança"
git push -u origin minha-branch
```

Depois é só abrir o Pull Request no GitHub.
